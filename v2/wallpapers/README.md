# DEROX OS 2.0 wallpapers

The approved default design is the purple galaxy / mountain / lake DEROX OS 2.0 artwork generated for this project.

The image asset still needs to be committed here as `derox-2.0-default.jpg`. Until that binary is present and installed by the desktop image build, the wallpaper is approved artwork but is not yet configured as the system default.

Target desktop path: `/usr/share/backgrounds/derox/derox-2.0-default.jpg`.
