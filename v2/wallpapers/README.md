# DEROX OS 2.0 wallpapers

The approved default design is the purple galaxy / mountain / lake DEROX OS 2.0 artwork generated for this project.

The initial official vector wallpaper is committed as `derox-2.0-default.svg`. It still needs to be copied into the target root filesystem and selected in XFCE configuration; it is not yet active in a bootable image.

Target desktop path: `/usr/share/backgrounds/derox/derox-2.0-default.jpg`.
