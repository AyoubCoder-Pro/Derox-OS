# Contributing to DEROX OS

Thank you for your interest in improving DEROX OS. Contributions from the community are welcome.

## Ways to contribute

- Report bugs and hardware compatibility results through GitHub Issues.
- Suggest features and improvements.
- Fix bugs, improve documentation, or improve the build configuration.
- Review open Pull Requests and provide constructive feedback.

## Submit a change

1. Fork the repository.
2. Clone your fork and create a new branch.
3. Make a focused change.
4. Test it as far as you reasonably can. For ISO/build changes, include the build result and any relevant logs.
5. Commit your work with a clear message.
6. Push the branch to your fork and open a Pull Request against `main`.
7. Explain the reason for the change, what you changed, and how you tested it.

You do not need direct write access to this repository. Pull Requests are reviewed before they are merged.

## Community and licensing

Be respectful and helpful. Do not submit passwords, private data, copyrighted material you do not have permission to share, or third-party binaries without redistribution permission.

Your contributions to the original DEROX OS project are submitted under the repository's MIT License, unless you clearly state otherwise and the maintainers agree before the contribution is merged. Third-party components included in the distribution keep their own licenses.
