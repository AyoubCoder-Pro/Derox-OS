DEROX OS.

Two stages of one ambitious project: DEROX 1.0, built on Debian, and DEROX 2.0, a new independent Linux distribution now in development.

Testing preview: DEROX OS is an early project build. Boot, installer, Wi-Fi, Bluetooth, and hardware compatibility still need testing. Back up your data and do not replace your main operating system with this preview.

Two versions. One vision.

Version 1.0 • Stable project base

DEROX OS 1.0

Based on Debian 12 Bookworm with the XFCE desktop. The first DEROX release line.

Explore 1.0 source
Version 2.0 • In development

DEROX OS 2.0

A planned independent Linux distribution, designed around its own system architecture, desktop experience, boot theme, and tools.

Explore 2.0 development

DEROX 2.0 is not bootable or available as an ISO yet. Its design and build infrastructure are being developed.

DEROX 2.0 boot experience

A black-screen, purple-neon GRUB bootloader concept is being prepared for DEROX 2.0. The final artwork and boot integration will be published with the build once the image asset and ISO pipeline are ready.

Independent 2.0 vision

DEROX 2.0 is being designed as a separate distribution, not a Debian rebrand.

Network tools

NetworkManager and Bluetooth support are included in the build configuration; device testing is ongoing.

Suggested test setup

64-bit processor

AMD64 / x86_64 PC.

Memory

4 GB RAM suggested for initial testing; actual needs may vary.

Storage & USB

Keep at least 20 GB free for an installation test and use an 8 GB or larger USB drive for live media.

These are preliminary suggestions, not verified official minimum requirements. Compatibility testing is still in progress.
