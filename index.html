XFCE desktop

A traditional desktop designed to stay responsive on modest hardware.

Debian foundation

Built on Debian 12 Bookworm and its broad Linux software ecosystem.

Network tools

NetworkManager and Bluetooth support are included in the build configuration; device testing is ongoing.

Suggested test setup

64-bit processor

AMD64 / x86_64 PC.

Memory

4 GB RAM suggested for initial testing; actual needs may vary.

Storage & USB

Keep at least 20 GB free for an installation test and use an 8 GB or larger USB drive for live media.

These are preliminary suggestions, not verified official minimum requirements. Compatibility testing is still in progress.

Built in the open.

DEROX OS is developed publicly. Follow the build history, report bugs, and help improve hardware compatibility through the project repository.
